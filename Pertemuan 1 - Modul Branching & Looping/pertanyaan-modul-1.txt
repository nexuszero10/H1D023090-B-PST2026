2. Jelaskan bagaimana program membuat efek LED berjalan dari kiri ke kanan!
jawab : propes unutk membuat efek LED sequence menggunanan loop ledPin berdasarkan nomor yang ada di breadboardnya dengan menggunakan initiate nomor pin terendah dan increment ke ledPin nomor tertinggi ; setelah dilakukan increment +=1 maka lampu led dengan pin terendah akan berada dalam kondisi 'HIGH' (nyala) selama 0.1 second dan akan dalam akan berlanjut kondisi 'LOW' (mati) ; setelah mati akan melakukan increment dan melakukan kondisi HIGH, delay, LOW ke ledPin nomor lebih besar selanjutnya 


3. Jelaskan bagaimana program membuat LED kembali dari kanan ke kiri!
Jawab : proses untuk membuat efek LED sequence menggunakan loop ledPin berdasarkan nomor LEP yang ada di breadboardnya dengan menggunakan initiate nomor pin terenda dan decrement ke ledPin nomor terendah ; setelah silakukan decrement -=1 maka lampu led dengan pin tertinggi akan berada dalam kondisi 'HIGH' (nyala) selama 0.1 second dan akan berlanjut kondisi 'LOW' (mati) ; setelah mati akan melakukan decrement dan melakukan kondisi HIGH, delay, LOW ke ledPin nomor lebih besar selanjutnya

*perlu diketahui bahsa kedua loop increment dan decrement antar ledPin saling terhubung dengan spesifikasi dalam case ini program melakukan efek LED berjalan dari kiri ke kanan (ledPin nomor rendah ke tinggi) bdaru ika loop selesai maka dilanjutkan ke loop efek LED berjalan dari kanan ke kiri (ledPin nomor tinggi ke rendah)

4. Buatkan program agar LED menyala tiga LED kanan dan tiga LED kiri secara bergantian
dan berikan penjelasan disetiap baris kode nya dalam bentuk README.md!	
Jawab : Source Code
int timer = 100 ;

void setup() {
  // put your setup code here, to run once:
  for (int ledPin = 2; ledPin < 8; ledPin++){
    pinMode(ledPin, OUTPUT);
  }
}

void loop() {
  // menyalakan LED kiri (pin 2, 3, 4)
  for (int ledPin = 2; ledPin <= 4; ledPin++){
    digitalWrite(ledPin, HIGH);
  }

  // mematikan LED kiri
  for (int ledPin = 2; ledPin <= 4; ledPin++){
    digitalWrite(ledPin, LOW);
  }

  // menyalakan LED kanan (pin 2, 3, 4)
  for (int ledPin = 5; ledPin <= 7; ledPin++){
    digitalWrite(ledPin, HIGH);
  }

  // mematikan LED kanan
  for (int ledPin = 5; ledPin <= 7; ledPin++){
    digitalWrite(ledPin, LOW);
}
